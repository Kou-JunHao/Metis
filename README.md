## Features

- **Glassmorphism UI**: Beautiful, modern translucent interfaces.
- **Customizable Engines**: Easily manage your favorite search engines, sort them, and add your own via UI.
- **Widgets & Clock Options**: Deeply customizable clock typography, size, and widgets.
- **Backgrounds & Themes**: Local upload, external URL, or preset wallpaper sources. Dynamic dark/light mode.
- **Privacy First**: Fully local. No tracking, no data collection. All settings stored safely in your browser.

## Getting Started

### Prerequisites

Ensure you have Node.js installed.

```bash
node -v
npm -v
```

### Installation

1. Clone the repository:
```bash
git clone https://github.com/YourUsername/Metis.git
cd Metis
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
